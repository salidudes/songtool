# Songtool

Persönliches Songwriting-Tool: Töne singen → Noten sehen → Lyrics, Akkorde und Chordsheet.

Live: https://salidudes.github.io/songtool/

- `index.html` – die komplette App (wird aus `src/` gebaut)
- `src/` – Quellteile; bauen mit `python3 src/build.py` im Repo-Hauptordner
- Songs werden lokal im Browser gespeichert (Export/Import im Chordsheet-Tab)
